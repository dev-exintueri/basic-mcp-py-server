# 포크해서 쓰는 사람을 위한 주석 체계

**목표:** 이 저장소를 base 로 삼아 자기 MCP 서버를 만드는 사람이 **어디를 바꾸고 어디를 건드리면 안 되는지** 코드만 읽고 알 수 있게 한다. 그리고 그 주석 방식을 규칙으로 명문화해 앞으로 쓰이는 코드가 같은 품질을 유지하게 한다.

**선행 조건:** `docs/superpowers/plans/2026-07-26-log-retention-flag.md` 를 **먼저 구현한다.** 그 계획은 `__main__.py`·`app.py`·`README.md` 를 고치고 정확한 코드 스니펫 매칭에 의존하므로, 주석이 먼저 들어가면 스니펫이 어긋난다.

---

## 1. 진단

브레인스토밍에서 11개 모듈을 전부 읽고 얻은 결론이다.

**기존 주석은 이미 충실하다.** 단순 설명이 아니라 함정을 기록하고 있다.

| 위치 | 기록하고 있는 것 |
|---|---|
| `registry.py:25-37` | 락이 없는 이유와 그것이 성립하는 전제 |
| `logsetup.py:69-84` | 회전 실패 시 상태를 바꾸는 순서가 전부라는 것 |
| `access.py:72-77` | 로그 줄 위조와 은폐를 막는 이유 |
| `app.py:292-297` | 이 한 줄이 `build_servers()` 뒤에 와야 하는 이유 |
| `admin.py:222-226` | 이 `return` 이 없으면 정상 종료마다 ERROR 가 남는다 |

따라서 **"주석 추가"를 밀도 보강으로 읽으면 할 일이 거의 없다.**

**없는 것은 응용 축이다.** 포크한 사람 관점의 정보가 어디에도 없다.

- `build_mcp()`(`mcp_server.py:69`)가 도구를 더하는 지점이라는 말이 없다
- 이름이 여러 곳에 박혀 있는데 **무엇이 무엇과 짝인지** 어디에도 없다 (아래)
- 깨면 안 되는 불변식이 파일마다 흩어져 있어 목록으로 잡히지 않는다

### 이름의 짝 관계

포크한 사람이 가장 먼저 하는 일이 이름 바꾸기다. 실제 결합은 이렇다 — **짐작과 다르므로 주석에 정확히 적어야 한다.**

| 짝 | 위치 | 성질 |
|---|---|---|
| 로그 파일명 ↔ 청소 패턴 | `logpaths.py:17` 의 `LOG_GLOB` ↔ `logpaths.py:101` 의 `log_file_name()` | 둘 다 `mcp-test-server.` 접두사를 쓴다. **한쪽만 바꾸면 로그가 영영 지워지지 않는다.** 이 결합은 `logpaths.py` 안에서 닫혀 있다 |
| 플러그인 이름 ↔ 설정 조회 | `plugin.json` 의 `name` ↔ `marketplace.json` 의 `plugins[].name` ↔ `logpaths.py:21` 의 `_PLUGIN_ID_PREFIX` | 플러그인 ID 는 `<plugin-name>@<marketplace-name>` 이다. 접두사가 어긋나면 `log_dir` 플러그인 설정을 조용히 못 읽는다 |
| MCP 서버 키 ↔ 권한 규칙 | `.mcp.json` 의 `test-server` ↔ `mcp__plugin_mcp-test_test-server__*` | 도구의 전체 이름을 만든다 (`README.md:76`) |
| `FastMCP("mcp-test-server")` | `mcp_server.py:74` | **어디와도 연결되지 않는다.** 로그 파일명과도 무관하다. 자유롭게 바꿔도 된다 |

**주석 규칙이 없다.** `CLAUDE.md` 에는 `docs/claude-base/` 참조 규칙과 질문 기록 규칙만 있다. 지금 코드가 이 품질인 것은 암묵적 관행일 뿐, 포크한 사람이나 다음 세션이 이를 유지할 근거가 없다.

## 2. 결정

두 가지를 만든다.

| 산출물 | 내용 |
|---|---|
| **(A) 응용 축** | 11개 모듈 독스트링 끝에 `## 응용할 때` 절을 붙인다 |
| **(B) 주석 규칙** | `CLAUDE.md` 에 절을 추가한다. 새로 발명하지 않고 이 코드의 관행을 명문화한다 |

**표기 방식은 산문이다.** `# EXTEND:` 같은 grep 가능한 마커를 쓰지 않는다. `grep` 한 번으로 목록을 얻는 편의를 잃는 대신, 기존 한국어 산문 독스트링과 일관성을 지킨다. 이 저장소의 주석은 한 줄짜리 표지가 아니라 문단으로 이유를 적는 방식이고, 마커는 그 결과 이질적으로 보인다.

## 3. `## 응용할 때` 절의 형식

모듈 독스트링 **끝에** 둔다. 항상 아래 세 축으로 쓰되, **해당 없는 축은 생략한다.**

1. **바꿔도 되는 것** — 자기 서버에 맞게 고칠 지점
2. **바꾸면 함께 바꿔야 하는 것** — 짝이 되는 다른 파일의 위치를 함께 적는다
3. **깨면 안 되는 것** — 어기면 조용히 망가지는 불변식

만질 일이 없는 파일이면 **"여기는 그대로 둬도 된다"를 명시한다.** 안 만져도 된다는 것도 목록의 일부다.

### 모듈별 축

구현자가 무엇을 쓸지 알 수 있도록 요지만 적는다. 문장은 구현 시점에 코드를 보고 쓴다.

| 모듈 | 응용 축의 요지 |
|---|---|
| `mcp_server.py` | **바꾼다:** `build_mcp()` 안이 도구를 더하는 곳. `FastMCP(...)` 이름은 어디와도 연결되지 않으니 자유롭게 바꾼다. **깨지 마라:** `@mcp.tool()` 아래 `@_logged` 순서 |
| `registry.py` | **바꾼다:** `SessionRecord` 필드, `session_view()` 의 출력. **함께:** 필드를 늘리면 `admin.py` 의 `_ROW` 열과 `auth.py` 의 `touch()` 호출. **깨지 마라:** 읽고 고치는 사이에 `await` 금지 |
| `auth.py` | **바꾼다:** `read_identity()` 의 통과 조건 — 진짜 인증을 넣는 자리. **함께:** `Identity` 필드를 늘리면 `registry.touch()`. **깨지 마라:** `AUTH_SCOPE_KEY` 스키마는 `access.py` 와의 계약 |
| `admin.py` | **바꾼다:** `_PAGE`/`_SESSIONS`/`_ROW` 템플릿, 라우트. **깨지 마라:** `log_stream` 의 `should_stop()` `return`, 값 삽입 전 `html.escape()` |
| `app.py` | **바꾼다:** `DEFAULTS`, `build_stack()` 의 조립. **깨지 마라:** `AccessLogMiddleware` 가 `AuthMiddleware` 바깥, `uvicorn.error` 레벨 복원은 `build_servers()` 뒤, 관리 리스너는 `ADMIN_HOST` 고정 |
| `logpaths.py` | **바꾼다:** `DEFAULT_LOG_DIR`, `LOG_GLOB`, `log_file_name()`, `_PLUGIN_ID_PREFIX`. **함께:** `LOG_GLOB` 과 `log_file_name()` 은 반드시 같이 — 한쪽만 바꾸면 로그가 영영 안 지워진다. `_PLUGIN_ID_PREFIX` 는 `plugin.json` 의 `name` 과. **깨지 마라:** `purge_logs` 가 `LOG_GLOB` 비재귀로만 보는 것 — 넓히면 남의 파일을 지운다 |
| `logsetup.py` | **바꾼다:** `ClockFormatter.format()` 의 줄 형식, 기본 레벨. **깨지 마라:** 핸들러는 루트 로거에, `configure_logging()` 은 `main()` 에서만 |
| `__main__.py` | **바꾼다:** CLI 인자. **깨지 마라:** 로깅 준비 후 경고 출력, `BaseException` 포착, `finally` 의 `logging.shutdown()` |
| `access.py` | 그대로 둬도 된다. 고칠 일은 `_log()` 의 필드 정도. **깨지 마라:** 조립된 줄에 대한 `\r`/`\n` 이스케이프 |
| `logstream.py` | 그대로 둬도 된다. **깨지 마라:** 큐에 `LogRecord` 가 아니라 포맷된 문자열을 넣는 것, `publish()` 가 예외를 삼키는 것 |
| `__init__.py` | 패키지 진입점. 어느 파일부터 읽어야 하는지 안내한다 |

## 4. 밀도 보강 — 여섯 곳

전면 보강이 아니다. 읽으면서 실제로 찾은 갭만 고친다.

| 위치 | 없는 것 | 조치 |
|---|---|---|
| `logsetup.py:22`, `:50`, `:75` | "스펙 §2 / §3.3 / §4.4" 가 **어느 문서인지 없다.** 절 번호는 유효하다 — 대상은 `docs/superpowers/specs/2026-07-25-server-logging-design.md` 다 | 첫 참조에 파일 경로를 적고, 이후는 절 번호만 |
| `mcp_server.py:76-77` | `@mcp.tool()` 과 `@_logged` 의 **순서**가 왜 그래야 하는지. 응용하는 사람이 가장 먼저 흉내 낼 코드인데 뒤집으면 조용히 깨진다 | 왜 그 순서인지, 뒤집으면 무엇이 어긋나는지 |
| `admin.py:64-127` | HTML 템플릿의 `{{ }}` 이중 중괄호가 `.format()` 때문이라는 사실 | 템플릿 위에 한 줄 |
| `admin.py:249` | `_toggle` 이 왜 클로저 팩토리인지 | 독스트링 |
| `logpaths.py:26` | `_clean` 이 `expanduser` 와 `resolve` 를 함께 하는 이유 | 독스트링 |
| `__init__.py` | 1줄뿐 | 진입점 안내 (3절의 응용 축과 겸함) |

### 비목표

**자명한 멤버에는 독스트링을 붙이지 않는다.** `registry.py` 의 `get`/`all`/`remove`/`block`/`is_blocked` 가 그렇다. 이 코드베이스는 76개 `def` 중 일부만 독스트링을 갖는데 그것은 태만이 아니라 판단이다. 규칙이 "모든 함수에 주석"으로 읽히면 코드가 나빠진다 — 규칙 본문에 이 경계를 명시한다.

## 5. `CLAUDE.md` 에 추가할 규칙

별도 파일로 빼지 않고 본문에 직접 쓴다. 현재 52줄로 짧고, 예시를 코드 경로 인용으로 대체하면 30줄 안에 담긴다. 아래가 넣을 내용이다.

````markdown
## 코드 주석

이 저장소의 코드는 **포크해서 자기 MCP 서버를 만드는 데 쓰인다.** 주석은
그 독자를 위해 쓴다.

### 무엇을 쓰나

- **모듈 독스트링** — 이 파일의 목적 한 줄, 그리고 이 파일에서 가장
  비자명한 성질. 예: `access.py` 는 왜 `AuthMiddleware` 바깥에 서는지,
  `registry.py` 는 왜 락이 없는지.
- **함수 독스트링** — 무엇을 하는지에 더해 **왜 이 모양인지.** 왜 따로
  떼어냈는지(`app.py` 의 `build_servers`), 왜 미리 확인하는지
  (`app.py` 의 `ensure_port_free`), 상태를 바꾸는 순서가 왜 중요한지
  (`logsetup.py` 의 `DailyFileHandler.emit`).
- **인라인 `#`** — "이건 틀린 것처럼 보이는데 아니다" 에만 쓴다.
  예: `auth.py:147`, `app.py:292`, `access.py:72`.

### 무엇을 쓰지 않나

- **자명한 멤버에는 독스트링을 붙이지 않는다.** `registry.py` 의
  `get`/`all`/`remove`/`block` 이 그렇다. 이름이 이미 답이면 침묵이 옳다.
  **"모든 함수에 주석" 은 이 규칙이 아니다.**
- 코드를 그대로 옮겨 적지 않는다.

### `## 응용할 때`

모듈 독스트링 **끝에** 이 절을 둔다. 포크한 사람이 이 파일에서 무엇을 할
수 있는지 알려주는 자리다. 세 축으로 쓰고 해당 없는 축은 생략한다.

1. **바꿔도 되는 것**
2. **바꾸면 함께 바꿔야 하는 것** — 짝이 되는 다른 파일의 위치를 적는다
3. **깨면 안 되는 것** — 어기면 조용히 망가지는 불변식

만질 일이 없는 파일이면 그렇다고 적는다. 그것도 정보다.

**새 모듈을 만들면 이 절도 함께 쓴다.**

### 언어와 인용

- 한국어로 쓴다. 코드 식별자는 원형 그대로 둔다.
- 설계 문서를 인용할 때는 **파일 경로와 절 번호를 함께** 적는다.
  `스펙 §4.4` 만으로는 어느 문서인지 알 수 없다.
````
